### Cisco WWAI Multi-Agent Platform

Led the technical architecture of an AI workforce-planning platform at enterprise scale. Built a LangGraph multi-agent system with a routing layer that classifies each request and dispatches it to a domain-specialised agent, each holding least-privilege access to approved Workday and Finance REST endpoints.

The design decision that matters: **the LLM never touches the data directly.** It selects and parameterises calls; the platform executes them. Every action stays auditable and no model output can widen its own access. Processes roughly 2M records in under five seconds and turned a multi-day planning cycle into hours. Deployed on OpenShift and Kubernetes.

### Content Moderation Agent — Renaissance Learning

Architected the company's first production AI product: a content-moderation agent built on a locally fine-tuned Qwen 2.5 model inside a NestJS/TypeScript platform.

The interesting half is the evaluation pipeline — synthetic data generation, reinforcement learning from eval results, and blind evaluations where graders could not reliably distinguish AI output from human. Reached 100% accuracy on the moderation filter and under 1% hallucination on domain tasks, then integrated across every production agent on a platform serving 44 million students and teachers daily.

### MCP Chain of Draft Prompt Tool

An open-source Model Context Protocol server, and my most-starred repository. MCP gives AI agents one scoped interface to tools and context instead of bespoke glue code per integration. Adopted by 30+ engineers, driven through live-coded tutorials and internal deep-dives rather than documentation alone.

### Block Brain Puzzle

A browser-based logic puzzle inspired by Genius Square: 62,208 valid board configurations generated from a seven-dice roll. I built the puzzle generator, the solver used to validate that every generated board is actually solvable, the timed scoring system, and shareable URLs that encode both board state and completion time.

Submitted as my final project for **CS50 at Harvard**, where it received a 100. Built with AI-assisted development throughout, including agent-driven iteration on game logic and UI.

### CarParts.com Digital Asset Platform

E-commerce digital asset management infrastructure for a publicly traded auto parts retailer. Python microservices on AWS EKS with Apache Kafka event-driven messaging and Zookeeper coordination, decoupling asset transformation, indexing and downstream sync so that one slow consumer could not stall the pipeline. Delivered a 500% increase in processing speed.
